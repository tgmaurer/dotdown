Privacy

Dwindle collects nothing. No accounts, no cookies, no analytics, no ads, no trackers.

Your countdown lives in the link

The name, the date and the goals are stored in the link itself, after the #. Browsers never send that part to a server, so it never reaches the host or me. Anyone you give the link to can read it, so share it the way you would share the goals themselves.

What stays on your device

Your browser keeps the last countdown you opened, so the bare address can bring it back. A countdown saved to the home screen also remembers its latest edits there. The browser also keeps a copy of the app’s files so Dwindle opens quickly and works offline. All of this stays in your browser and is never sent anywhere. Clearing the website data for this site in your browser’s settings removes it.

Hosting

Dwindle is hosted on GitHub Pages. When you open it, GitHub logs your IP address for security reasons. GitHub does this, not Dwindle, and I cannot see those logs. See GitHub Pages: data collection and the GitHub Privacy Statement.

The font is served with the app, so no other server is contacted. The “Source” and “More by me” links lead to GitHub, where GitHub’s own privacy statement applies.
